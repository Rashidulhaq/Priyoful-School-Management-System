# 🌻 প্রিয়ফুল পাঠশালা (Priyoful Pathshala)
### *School & Comprehensive Educational Management System (ERP)*

> **"শিখবো, ফুটবো, গড়বো দেশ"**  
> সুবিধাবঞ্চিত শিশুদের জন্য একটি উন্মুক্ত, মানসম্মত ও ভালোবাসার বিদ্যাপীঠ — পরিচালিত হচ্ছে **QSP ফাউন্ডেশন**-এর সহায়তায়।

## 🌟 পরিচিতি ও উদ্দেশ্য (Overview & Mission)

**প্রিয়ফুল পাঠশালা** একটি অলাভজনক ও মানবিক উদ্যোগ, যার লক্ষ্য সমাজের নিম্নআয়ের এবং সুবিধাবঞ্চিত পরিবারের শিশু-কিশোরদের (১ম শ্রেণি থেকে ৫ম শ্রেণি পর্যন্ত) সম্পূর্ণ বিনামূল্যে নৈতিক, আনন্দময় ও আধুনিক শিক্ষা প্রদান করা।

এই প্ল্যাটফর্মটি একাধারে একটি **পাবলিক পোর্টাল** (স্কুলের ইতিহাস, কার্যক্রম, ফটো গ্যালারি, অনুদান ও স্পনসরশিপ ব্যবস্থা) এবং একটি শক্তিশালী **স্কুল ম্যানেজমেন্ট সিস্টেম (ERP)** (শিক্ষক, শিক্ষার্থী, হাজিরা, ফলাফল, অ্যাকাউন্টিং ও অডিট ট্র্যাকিং) হিসেবে নির্মিত।

## 📸 মূল হাইলাইটস ও আলোকচিত্র (Visual Showcase)

- **আসল দেওয়ালচিত্র ও প্রাঙ্গণ (`pic1.jpg`):** হোমপেজে সিনেমাটিক ও নান্দনিক অ্যাম্বিয়েন্ট ব্যাকগ্রাউন্ড এবং মূল ফিচার কার্ড।
- **শ্রেণিকক্ষের আনন্দ পাঠ (`pic2.jpg`):** শ্রেণিকক্ষে শিশুদের হাতে-কলমে শিক্ষা ও আনন্দময় পাঠদান কার্যক্রম।
- **উচ্ছ্বল মুখ ও উৎসব (`pic3.jpg`):** শিশুদের বার্ষিক খেলাধুলা, সাংস্কৃতিক উৎসব ও রঙিন স্মৃতি।
- **নেতৃত্ব ও দিকনির্দেশনা (`bahar_vi.jpg`):** **মাহমুদুল হাসান বাহার** (পরিচালক ও প্রধান স্বপ্নদ্রষ্টা, প্রিয়ফুল পাঠশালা • QSP ফাউন্ডেশন)।
- **উচ্চশিক্ষা পৃষ্ঠপোষক স্লট:** বাংলাদেশ ইউনিভার্সিটি অব বিজনেস অ্যান্ড টেকনোলজি (**BUBT**)-এর সম্মানিত উপাচার্য (VC) মহোদয়ের দিকনির্দেশনা ও পৃষ্ঠপোষকতা।

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### ১. 🌐 পাবলিক ওয়েবসাইট (Public Website)
- **ডায়নামিক হিরো সেকশন:** স্কুলের আসল দেওয়ালচিত্রের আবছা-স্পষ্ট ব্যাকগ্রাউন্ড, সরাসরি পরিসংখ্যান (শিক্ষার্থী, শিক্ষক, শ্রেণি) ও কল-টু-অ্যাকশন।
- **আমাদের গল্প ও ইতিহাস (About Us):** প্রিয়ফুল প্রতিষ্ঠার পটভূমি, স্বপ্ন, লক্ষ্য এবং পরিচালকের অনুপ্রেরণামূলক বাণী।
- **ক্লাস ও কারিকুলাম (Classes 1–5):** প্রতিটি ক্লাসের বিষয়ভিত্তিক সিলেবাস, রুটিন এবং পাঠ্যপুস্তকের তালিকা।
- **শিক্ষক ও স্বেচ্ছাসেবী পরিচিতি (Teachers & Volunteers):** নিবেদিতপ্রাণ শিক্ষক ও মেন্টরদের প্রোফাইল।
- **রঙিন ফটো অ্যালবাম (Photo Gallery):** ক্যাটাগরিভিত্তিক (শ্রেণিকক্ষ, আর্ট, খেলাধুলা, উৎসব) হাই-কোয়ালিটি ফটো প্রদর্শনী ও লাইটবক্স প্রিভিউ।
- **নোটিশ ও সংবাদ (Notice Board & News):** রিয়েল-টাইম নোটিশ ও স্ক্রলিং মার্কিউ হেডলাইন।
- **স্বচ্ছ অনুদান ও স্পনসরশিপ (Donation & Sponsorship):** বিকাশ (bKash), নগদ (Nagad), ব্যাংক অ্যাকাউন্ট বিবরণী ও তাৎক্ষণিক ডোনেশন রিসিপ্ট জেনারেটর।

### ২. 👨‍🏫 শিক্ষক পোর্টাল (Teacher Portal)
- শিক্ষক রোলভিত্তিক ড্যাশবোর্ড ও ক্লাসরুম অ্যাসাইনমেন্ট।
- দৈনিক শিক্ষার্থী হাজিরা গ্রহণ ও মাসিক পার্সেন্টেজ গণনা।
- পরীক্ষা অনুযায়ী বিষয়ভিত্তিক মার্কশিট ও গ্রেড এন্ট্রি।
- শিক্ষার্থীদের সাথে সরাসরি ফিডব্যাক ও নোটিশ আদান-প্রদান।

### ৩. 🛡️ অ্যাডমিন ও ইআরপি ম্যানেজমেন্ট (Super Admin ERP)
- **শিক্ষার্থী ব্যবস্থাপনা:** নতুন ভর্তি, প্রোফাইল আপডেট, আইডি কার্ড তৈরি ও অভিভাবকের তথ্য।
- **শিক্ষক ও স্টাফ ব্যবস্থাপনা:** নতুন নিয়োগ, ডেজিগনেশন এবং রোল পারমিশন নির্ধারণ।
- **আর্থিক হিসাব ও ডোনেশন লেজার:** প্রতিটি প্রাপ্ত অনুদান ভেরিফিকেশন, দৈনন্দিন খরচের ভাউচার এবং স্বচ্ছ ব্যালেন্স ট্র্যাকিং।
- **গ্যালারি ও কনটেন্ট ম্যানেজার:** নতুন ছবি আপলোড, ড্র্যাগ অ্যান্ড ড্রপ, ক্যাপশন এবং ক্যাটাগরি ফিল্টার।
- **নিরাপদ অডিট লগ:** সিস্টেমের প্রতিটি ডেটা এন্ট্রি ও পরিবর্তনের স্বয়ংক্রিয় টাইমস্ট্যাম্পড অডিট ট্রেইল।

## 🛠️ প্রযুক্তিগত কাঠামো (Tech Stack)

| স্তর | ব্যবহৃত প্রযুক্তি | বিবরণ |
| :--- | :--- | :--- |
| **Frontend** | React 19, TypeScript, Vite 8 | সুপার ফাস্ট এসপিএ (SPA) আর্কিটেকচার |

## ⚡ লোকাল ডেভেলপমেন্ট সেটআপ (Local Setup Guide)

### পূর্বশর্ত (Prerequisites):
- [Node.js](https://nodejs.org/) (Version 18.0 বা তার বেশি)
- [npm](https://www.npmjs.com/) অথবা [bun](https://bun.sh/)

### ধাপসমূহ (Steps):

1. **রিপোজিটরি ক্লোন করুন:**
   ```bash
   git clone https://github.com/your-username/priyoful-pathshala.git
   cd priyoful-pathshala
   ```

2. **ডিপেনডেন্সি ইনস্টল করুন:**
   ```bash
   npm install
   ```

3. **এনভায়রনমেন্ট ভেরিয়েবল কনফিগারেশন:**
   `.env.example` ফাইল কপি করে `.env` তৈরি করুন এবং প্রয়োজনীয় ফায়ারবেস কনফিগ দিন:
   ```bash
   cp .env.example .env
   ```

4. **লোকাল সার্ভার চালু করুন:**
   ```bash
   npm run dev
   ```
   অ্যাপ্লিকেশনটি ব্রাউজারে দেখতে ভিজিট করুন: `http://localhost:3000`

5. **প্রোডাকশন বিল্ড ও টাইপচেক:**
   ```bash
   npm run build
   npm run lint
   ```

## 🔒 নিরাপত্তা ও অ্যাক্সেস কন্ট্রোল (Security & RBAC)

- **পাবলিক ভিজিটর:** ওয়েবসাইট ব্রাউজ, ফটো গ্যালারি দেখা, নোটিশ পড়া ও অনুদান পাঠানো।
- **শিক্ষক (Teacher):** শুধুমাত্র নির্ধারিত ক্লাসের শিক্ষার্থীদের তথ্য দেখা, হাজিরা নেওয়া ও মার্কস ইনপুট দেওয়া।
- **সুপার অ্যাডমিন (Admin):** পূর্ণাঙ্গ নিয়ন্ত্রণ — ফাইন্যান্সিয়াল অনুমোদন, ইউজার অ্যাকাউন্ট ক্রিয়েশন ও কনটেন্ট মডারেশন।
